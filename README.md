## 🔄 진행 방식

📣 **스터디는 매주 목요일 19:00에 진행됩니다.** 📣

- 스터디원 모두는 매주 **5개의 아이템**을 읽어옵니다.
- 각자 맡은 파트의 아이템에 대해 **Issue로 질문을 등록**합니다.
- 읽어온 아이템 중 **하나를 골라 기술 블로그 글로 정리**해 **PR로 올립니다.**
  - 스터디에서는 정리해 온 내용을 공유하고 함께 이야기를 나눕니다.

<br/>

### Issue — 질문 등록

- 각자 맡은 아이템에 대한 **질문(또는 문제)** 을 Issue로 등록합니다.
- 스터디 진행 전까지 등록하고, 해당 장의 **label 적용** + 본인 포함 **assign** 을 지정합니다.
- 제목 형식 : `[item 3] 타입은 값의 집합이라는 관점에서 유니온과 인터섹션의 차이는 무엇인가요?`
- 등록된 질문에 대해서는 미팅 시점으로부터 **일주일 내에 각자 1개 이상의 코멘트**를 작성합니다.
  - 함께 토론하거나, 문제를 내는 식으로 자유롭게 참여합니다.
  - 질문자가 질문을 올리면 그 아래에 스터디원 모두가 코멘트를 답니다.
  - 모든 스터디원이 코멘트를 단 뒤, **맨 마지막에 질문자가 생각한 최종 답을 작성**합니다.

<br/>

### Pull Request — 기술 블로그 등록

- 그 주에 공부한 아이템 중 **글로 남기고 싶은 주제 하나**를 정해 기술 블로그 형식으로 정리합니다.
- **글 제목으로 폴더를 만들고, 그 안에 본인 닉네임으로 파일을 생성**합니다.
  - 폴더명 : 기술 블로그 글 제목 (책의 아이템 제목과 달라도 됩니다.)
  - 파일명 : 본인 닉네임 (`유월.md`)
  - 같은 주제로 여러 명이 글을 쓴다면 **한 폴더 안에 각자의 닉네임 파일**로 들어갑니다.
- Issue와 마찬가지로 해당 장의 **label 적용** + 본인 **assign** 을 지정합니다.
- 제목 형식 : `유니온의 인터페이스보다는 인터페이스의 유니온 - 유월`
- **최소 3명의 승인** 을 받아야 머지할 수 있습니다.

<br/>

### 컨벤션

| 항목                  | 형식                  | 예시                                                             |
| --------------------- | --------------------- | ---------------------------------------------------------------- |
| Issue 제목            | `[item N] 질문 내용?` | `[item 3] 유니온과 인터섹션의 차이는 무엇인가요?`                |
| PR 제목 / 커밋 메시지 | `글 제목 - 작성자`    | `유니온의 인터페이스보다는 인터페이스의 유니온 - 유월` |
| 폴더명                | `글 제목`             | `유니온의 인터페이스보다는 인터페이스의 유니온`                  |
| 파일명                | `닉네임.md`           | `유월.md`                                                        |
